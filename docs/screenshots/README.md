# Screenshots (demo data)

Rendered from the real Flutter app in Chromium (390×844 @2x) with **fake data** from `mobile/lib/demo_main.dart`
(an in-memory HTTP adapter behind the real `ApiClient`; no backend, nothing here is real business data).

Run it yourself:

```
cd mobile
flutter run -d chrome -t lib/demo_main.dart
# or: flutter build web -t lib/demo_main.dart --release
```
